# Dashboard overrides — Spend Notebook

Auditor-first personal ledger for India. Clarity over decoration.

## Intent
Help a normal person answer in 5 seconds:
1. How much did I spend today / this month?
2. How much budget is left?
3. Where did money go?
4. Add a spend without thinking.

## Layout (mobile-first)
1. Header: brand + month remaining
2. KPI strip: Today | Week | Month | Left
3. **Add spend** (primary) — typing first; voice secondary
4. Charts: category bars + last 14 days
5. Recent list

## Interaction
- Amount field is largest; numeric keyboard
- Merchant chips from favorites under the field
- One primary Save button (charcoal, 6px radius — not pill)
- Confirm before delete
- Voice never auto-saves

## Charts
- Horizontal bar: category comparison (sorted)
- Column/bar: daily spend last 14 days
- Always show numbers as text beside visuals
